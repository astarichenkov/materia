# Day 35 — демонстрация (3–5 минут)

Цель: показать, что автоматически обработанную лекцию можно довести до
качественного документа без повторного распознавания речи.

Предварительно: приложение запущено с `LECTURE_STORAGE_ROOT`, указывающим на
каталог с уже обработанной английской лекцией (перевод + слайды). Ollama нужна
только для «Пересоздать конспект» и «Повторить перевод».

## 0:00–0:30 — библиотека

1. Откройте `/`.
2. Введите часть названия в «Поиск по названию/теме», выберите `Перевод: Есть
   перевод`, нажмите «Применить».
3. У нужной лекции нажмите **Редактор**.

## 0:30–2:00 — перевод и качество

1. Вкладка **Перевод**. Показываются таймкоды, EN, RU и статус.
2. Фильтр **Только WARNING** → у проблемного сегмента нажмите **Повторить
   перевод**. Появится предложение модели с провайдером и предупреждением.
3. Отредактируйте RU-текст вручную и нажмите **Сохранить изменённые**.
   Сообщение: «Перевод сохранён как версия #N; конспект помечен устаревшим».
4. Нажмите **Проверено** у сегмента — статус меняется на `REVIEWED`.
5. Обратите внимание на блок качества сверху: WARNING / вручную / проверено /
   устарело — это журнал проверок, а не «точность».

## 2:00–3:00 — конспект и безопасный preview

1. Вкладка **Конспект**: измените заголовок/абзац.
2. **Предпросмотр** — HTML рендерится сервером, сырой HTML/JS не исполняется.
3. **Сохранить конспект** → новая ревизия.
4. (Опционально) **Пересоздать конспект из перевода** — новая ревизия
   `AI_ASSISTED`, предыдущая остаётся в истории.

## 3:00–4:00 — повторный экспорт и слайды

1. Нажмите **Russian DOCX** — экспорт собирается из сохранённых ревизий и
   существующих слайдов.
2. Скачайте `notes.ru.docx`: исправленный текст присутствует, изображения на
   месте.
3. Нажмите **Notes DOCX**, затем **Bilingual DOCX**.
4. Вкладка **Слайды** — те же изображения и таймкоды (повторного извлечения не
   было).

## 4:00–5:00 — история и восстановление

1. Вкладка **История изменений**, документ «Конспект».
2. Выберите «От» = исходная ревизия, «До» = текущая → **Сравнить** (построчный
   diff).
3. **Восстановить «До»** → создаётся новая ревизия с прежним содержимым,
   история не теряется.
4. Снова **Notes DOCX** — документ отражает восстановленную версию.

## Что подчеркнуть

- Whisper и скачивание не запускаются: в логе нет стадий, `TRANSCRIPTION`
  checkpoint не меняется.
- При правке оригинала затронутые сегменты перевода становятся `STALE` и не
  выдаются за актуальные.
- Конфликт версий (две вкладки) даёт `409`, а не потерю данных.
- `notes.ru.docx` собирается атомарно: при ошибке предыдущий файл остаётся.
- `GET /diagnostics` показывает, какие зависимости установлены.
