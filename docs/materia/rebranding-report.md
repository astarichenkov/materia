# Materia — отчёт о ребрендинге

## Бренд

- Основное написание в интерфейсе: **materia**.
- Слоган: **Контент, который работает на вас.**
- Подпись: **Загружайте. Обрабатывайте. Используйте.**
- Позиционирование: интеллектуальная библиотека для видео, аудио и других
  поддерживаемых материалов, а не только образовательная система.

## Что изменено в UI

- Appbar/логотип и все `<title>` — `materia` (+ название страницы).
- Главная: бренд, слоган, подпись, описание сценариев и бейджи возможностей.
- Библиотека, импорт, карточка материала, редактор, поиск, чат, Support,
  File Agent, Developer Assistant, настройки, диагностика, ошибки.
- Терминология: «лекция» → «материал» в пользовательских текстах.
- «Академическая лекция» сохранена как тип контента.
- Документ называется по сценарию: «Конспект», «Рецепт», «Диалоги»,
  «Транскрипция», «Перевод» и т. д.

## Что не изменено

Java-пакеты, классы `Lecture*`, таблицы `lecture*`, persisted enum values,
`/api/lectures/**`, `/lectures/**`, пути `lectures/<id>/…`. Это documented
legacy-совместимость. Новые `/materials/*` — только redirect-алиасы.

## Проверка

- `grep` по шаблонам и основным Java-строкам не находит «Lecture Processor» и
  пользовательских «лекций».
- Playwright: 30/30, включая бренд на главной, отсутствие Support в навигации,
  мобильную ширину и отсутствие горизонтального скролла.
- `scripts/smoke-ui.py`: все основные страницы отвечают 200.
