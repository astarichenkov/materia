# Система промптов Materia

## Что было не так

До Materia пользователь выбирал технический `OutputFormat`, а `PromptTemplate`
мог ему не соответствовать. `TemplateCompatibility` выдавал предупреждение, но
запуск не блокировался. `NotesAssembler` всегда удалял повторы и всегда добавлял
«# Конспект лекции» и `## Резюме`. Для рецепта, диалога и дословной
транскрипции это искажает содержание.

## Как устроено теперь

1. **Один системный промпт** = версия шаблона + контракт формата + параметры
   задания + правила достоверности.
2. **Пользовательское сообщение** содержит только `<transcript>…</transcript>`.
   Сценарий, тип материала и детализация никогда не попадают в данные.
3. **Сценарий выбирает шаблон**; ручной выбор шаблона разрешён, но:
   - отсутствующий шаблон → `INCOMPATIBLE` (fail-fast);
   - lossless-сценарий + LLM-формат → `INCOMPATIBLE`;
   - нерeкомендованный, но существующий шаблон → `WARNING` с рекомендацией.
4. **Сборка по политике**:
   - `SEMANTIC` — слияние заголовков, удаление дублей (конспект, FAQ);
   - `CHRONOLOGICAL` — порядок сохраняется, дубли не удаляются (пересказ, статья);
   - `STRUCTURED` — порядок и повторы значимы (рецепт, инструкция);
   - `DIALOGUE` — сырой порядок реплик, повторы сохраняются;
   - `LOSSLESS` — LLM не вызывается.
5. **Дополнительный summary-вызов** выполняется только для сценариев, где он
   полезен (`includeSummary`), а не для рецепта/диалога/пересказа.
6. **Проверка результата** — `ScenarioOutputValidator`: пустой ответ → ошибка;
   эхо инструкций, повторяющиеся заголовки, потерянные числа в рецепте,
   навязанные академические разделы и подозрительное усечение → предупреждения в
   `notes-quality.json` и на карточке материала.

## Пользовательские шаблоны

`/settings/prompts` показывает для каждого шаблона сценарии, которые его
рекомендуют. Копирование, редактирование, восстановление и удаление сохранены.
Версия и содержимое шаблона входят в fingerprint `TEXT_PROCESSING` через
`resolvedPrompt()` + версию профиля; изменение тела копии не перезапускает
Whisper автоматически и не запускает переработку без действия пользователя.

## Ограничения

- Малые локальные модели (`qwen3:1.7b`) могут возвращать лишние заголовки;
  валидатор предупреждает, но не переписывает документ.
- Diarization не реализована: сценарий «Диалоги» не изображает говорящих.
- Проверки качества эвристические, а не доказательство корректности.
