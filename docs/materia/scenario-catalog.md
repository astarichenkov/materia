# Каталог сценариев Materia

ID стабильны и хранятся в `lecture_processing_profile.scenario` и
`lecture_output_variant.scenario`. Версия сценария участвует в fingerprint.

| ID | Название | Формат | Шаблон | Сборка | LLM | Перевод |
|---|---|---|---|---|---|---|
| `notes` | Конспект | DETAILED_NOTES | scenario-notes-v1 | SEMANTIC | да | по настройкам языка |
| `academic-notes` | Академический конспект | DETAILED_NOTES | notes-academic-v1 | SEMANTIC | да | по настройкам |
| `short-summary` | Краткий пересказ | SHORT_SUMMARY | scenario-summary-v1 | CHRONOLOGICAL | да | по настройкам |
| `recipe` | Рецепт | RECIPE | scenario-recipe-v1 | STRUCTURED | да | по настройкам |
| `dialogue` | Диалоги | DIALOGUE | scenario-dialogue-v1 | DIALOGUE | да | по настройкам |
| `instruction` | Инструкция | STEP_BY_STEP | scenario-instruction-v1 | STRUCTURED | да | по настройкам |
| `article` | Статья | ARTICLE | notes-article-v1 | CHRONOLOGICAL | да | по настройкам |
| `faq` | FAQ | FAQ | notes-faq-v1 | SEMANTIC | да | по настройкам |
| `meeting-protocol` | Протокол встречи | MEETING_PROTOCOL | notes-meeting-v1 | CHRONOLOGICAL | да | по настройкам |
| `methodical-guide` | Методическое пособие | METHODICAL_GUIDE | notes-methodical-v1 | SEMANTIC | да | по настройкам |

| `translation` | Только перевод | TRANSLATION_ONLY | — | LOSSLESS | **нет** | да (существующая подсистема) |

## Контракты результата

Контракт формата (`OutputFormat.structureContract()`) добавляется в системный
промпт, а не в пользовательское сообщение. Сценарий может дополнительно задать
свои требования в тексте шаблона.

- Конспект: темы, идеи, факты/примеры (только из текста), выводы.
- Краткий пересказ: содержание, события/идеи в порядке изложения, детали,
  итог (только если он есть). Академические разделы запрещены.
- Рецепт: блюдо, ингредиенты с количествами или «количество не указано»,
  подготовка, шаги, замечания. Выдумывать граммовки, температуру и время нельзя.
- Диалоги: реплики по порядку, повторы сохраняются, имена не выдумываются.
- Инструкция: цель, что понадобится, шаги, проверка, предупреждения.
- FAQ: только реальные вопросы; короткий документ лучше выдуманных вопросов.
- `verbatim`: точный текст сегментов, реальные таймкоды, без пересказа.

## Свобода пользователя

Сценарий не привязан жёстко к типу источника: рецепт можно получить из обычного
видео, инструкцию — из вебинара, краткий пересказ — из лекции. Необычная
комбинация даёт предупреждение, но не блокируется, если она технически
исполнима. Блокируются только реально несовместимые пары (например, lossless
сценарий с форматом, требующим LLM, или отсутствующий шаблон).
