# UX-6. Wireframes ключевых экранов

Текстовые wireframes. Отражают **существующие** функции; новые backend-
возможности не рисуются. Элементы с `[ ]` — действия, `( )` — пояснение.
Масштаб: desktop 1440 px; mobile-схемы — 390 px.

---

- Не показывать одновременно «Обработать заново» и «Возобновить».

## 11. Правила для всех wireframes

1. Не рисовать функции, которых нет в backend (глобальный поиск по всем
   лекциям, per-job выбор модели, live upload %).
2. Не дублировать одно действие в двух местах.
3. Не показывать технические enum'ы/метрики на первом уровне.
4. Любая ошибка — с причиной и действием.
5. Любой пустой экран — с primary-действием.
6. Любая таблица на mobile — карточки или локальный скролл.
7. Любой интерактив — доступен с клавиатуры.
8. Support Assistant не рисуется в навигации, на главной, в библиотеке,
   мастере импорта и карточке лекции. Прямой `/support` не изображается как
   пользовательский сценарий.
9. Локальные MP3/M4A/WAV не показываются в `accept` и подписях, пока backend
   их не поддерживает (отложенная задача D1).
10. Раздел «База знаний»/глобальный RAG-поиск не рисуется (отложенная задача
    D3).
